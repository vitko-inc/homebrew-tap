# Vitko Homebrew tap

```sh
brew install vitko-inc/tap/vitko
```

Installs the [`vitko`](https://github.com/vitko-inc/vitko) command-line tool on macOS and Linux. The cask is updated automatically for each release.

Other ways to install are in the [vitko README](https://github.com/vitko-inc/vitko#install).
